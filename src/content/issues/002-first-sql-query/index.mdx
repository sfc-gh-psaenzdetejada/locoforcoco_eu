In this video we show how to use Cortex Code to write and execute your first SQL query against Snowflake.

- How to connect to your Snowflake account from CoCo

- Running it and seeing results inline

## Benefits

CoCo understands the context of your data and suggests relevant queries. No need to remember table or column names — just describe what you need in natural language.
