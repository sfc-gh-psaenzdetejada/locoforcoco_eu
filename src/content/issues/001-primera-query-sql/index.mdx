En este video mostramos como usar Cortex Code para escribir y ejecutar tu primera query SQL contra Snowflake.

## Lo que aprenderas

- Como conectarte a tu cuenta de Snowflake desde CoCo
- Escribir una query SELECT basica
- Ejecutarla y ver los resultados inline

## Beneficios

CoCo entiende el contexto de tus datos y te sugiere queries relevantes. No necesitas recordar los nombres de tablas o columnas — simplemente describe lo que necesitas en lenguaje natural.
